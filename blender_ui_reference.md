# Blender UI Rendering Reference for Rust Port

Extracted from Blender source (blender/blender main branch).

## 1. WIDGET ROUNDED RECTANGLE ALGORITHM (interface_widgets.cc)

### Corner Curve Resolution
```
WIDGET_CURVE_RESOLU = 9       // vertices per quarter-circle corner
WIDGET_SIZE_MAX = 9 * 4 = 36  // max vertices per widget outline
```

### Corner Vector (normalized quarter-circle, 9 points)
The `cornervec` array defines one quarter-circle from (0,0) to (1,0) arc:
```
cornervec[0] = {0.0, 0.0}
cornervec[1] = {0.195, 0.02}
cornervec[2] = {0.383, 0.067}
cornervec[3] = {0.55, 0.169}
cornervec[4] = {0.707, 0.293}   // ~45 degrees (sin45, cos45)
cornervec[5] = {0.831, 0.45}
cornervec[6] = {0.924, 0.617}
cornervec[7] = {0.98, 0.805}
cornervec[8] = {1.0, 1.0}
```

### Round Box Vertex Generation (`round_box__edges`)
For each corner, vertices are generated by scaling `cornervec` by the corner radius:
- **Bottom-left corner**: center at (rect.xmin + rad, rect.ymin + rad), arc from 180 to 270 deg
- **Bottom-right corner**: center at (rect.xmax - rad, rect.ymin + rad), arc from 270 to 360 deg
- **Top-right corner**: center at (rect.xmax - rad, rect.ymax - rad), arc from 0 to 90 deg
- **Top-left corner**: center at (rect.xmin + rad, rect.ymax - rad), arc from 90 to 180 deg

Inner and outer vertex rings are generated:
- **Outer ring**: at rect boundary
- **Inner ring**: inset by outline_width (typically 1px)

Corner flags: `CNR_BOTTOM_LEFT`, `CNR_BOTTOM_RIGHT`, `CNR_TOP_RIGHT`, `CNR_TOP_LEFT` (each 1.0 or 0.0)

### ROUNDBOX_CORNER constants
```
UI_CNR_TOP_LEFT     = (1 << 0)
UI_CNR_TOP_RIGHT    = (1 << 1)
UI_CNR_BOTTOM_RIGHT = (1 << 2)
UI_CNR_BOTTOM_LEFT  = (1 << 3)
UI_CNR_ALL          = 0xF
UI_CNR_NONE         = 0
```

## 2. WIDGET DRAWING ORDER (widgetbase_draw)

The exact drawing pipeline for every standard widget:

1. **Prepare inner colors**: solid fill OR gradient via `shadecolors4(inner_col, wcol->inner, wcol->shadetop, wcol->shadedown)`
2. **Prepare outline color**: from `wcol->outline`
3. **Prepare emboss color**: only if outline alpha > 0
4. **Batch all geometry** into `draw_widgetbase_batch()` using `GPU_SHADER_2D_WIDGET_BASE`
5. **Draw text and icon** via `widget_draw_text_icon()`

### Emboss Technique
- A 1px lighter line is drawn along the **bottom edge** of the widget
- Controlled by `draw_emboss()` checking `BUT_ALIGN_DOWN` alignment flag
- Creates subtle 3D raised appearance
- Emboss is skipped if widget is aligned to bottom of a group

### Gradient Shading
```
shadecolors4(col_inner, base_color, shadetop, shadedown)
// shadetop: added to top vertices (positive = lighter at top)
// shadedown: added to bottom vertices (negative = darker at bottom)
// Creates vertical gradient across widget face
```

## 3. TEXT AND ICON POSITIONING (widget_draw_text_icon)

### Icon Sizing
```
icon_size = 0.8 * BLI_rcti_size_y(rect)   // 80% of widget height
```

### Text Padding
```
text_padding_x = UI_TEXT_MARGIN_X * U.widget_unit / aspect
```

### Layout Order (left to right)
1. Icon (if present) - vertically centered in widget rect
2. Horizontal padding
3. Text - vertically centered, clipped to remaining width

### Text Emboss Shadow
- 1px dark shadow drawn below text for readability
- Uses theme text shadow color and alpha

## 4. DROP SHADOW (interface_draw.cc - draw_dropshadow)

```
clamped_aspect = smoothminf(aspect, 1.0, 0.5)
shadow_width   = width * clamped_aspect
shadow_offset  = min(shadow_width, rect_height - 2*radius)
inner_radius   = max(radius - pixelsize, 0.0)
shadow_radius  = radius + shadow_width - pixelsize
```

Shadow extends outward on left/right/top by `shadow_width` pixels.
Bottom is offset less by `shadow_offset`.
Uses `GPU_SHADER_2D_WIDGET_SHADOW` with alpha parameter.

## 5. ROUNDED RECTANGLE DRAWING (interface_draw.cc - draw_roundbox_4fv_ex)

```rust
// Parameters:
//   rect: target rectangle
//   inner1, inner2: gradient fill colors (top, bottom)
//   outline: border color
//   outline_width: border thickness (typically 1.0)
//   rad: corner radius
//   shade_dir: gradient direction (1.0 = top-to-bottom)
```

Uses `GPU_SHADER_2D_WIDGET_BASE` batch shader.
Passes `WidgetBaseParameters` struct with:
- Inner rect (rect inset by outline_width)
- Corner flags (1.0f or 0.0f per corner)
- Colors as float4 arrays

Blend mode: `GPU_BLEND_ALPHA`

### Numeric Constants
| Constant | Value | Usage |
|----------|-------|-------|
| Default corner radius | 3.0 | Standard widget rounding |
| Corner interpolation | 0.195, 0.55, 0.831, 0.98 | Quarter-circle sample points |
| Line width (curve outline) | 1.5 | Curve editor outlines |
| Line width (standard) | 1.0 | Normal lines |
| RGB ring line width | 2.5 | Color picker ring |
| Checker tile size | 8 | Alpha checker pattern |
| Stipple segments | 6 | Stipple cross pattern |

## 6. PANEL DRAWING (interface_panel.cc)

### Drawing Order
1. `panel_draw_aligned_backdrop()` - panel background
2. `panel_draw_aligned_widgets()` - header widgets (collapse icon, title, pin, drag)
3. `panel_draw_border()` - outline border

### Panel Header
- Height: `PNL_HEADER` (typically 24px at 1x scale, = `UI_UNIT_Y`)
- Collapse icon position: `xmin + size_y * 0.2`, `ymin + size_y * 0.14` (open) or `0.17` (closed)
- Collapse icons: `ICON_DOWNARROW_HLT` (open), `ICON_RIGHTARROW` (closed)
- Title X offset: `scaled_unit * 1.1` from collapse icon
- Title Y offset: `widget_rect.ymin - 2.0 / aspect`
- Font: `style->paneltitle` (regular panels), `style->widget` (sub-panels)

### Panel Background Colors (from theme)
- Open panel: `TH_PANEL_BACK` or `TH_PANEL_SUB_BACK`
- Header: `TH_PANEL_HEADER` or `TH_MATCH` (search highlight)

### Panel Border
- Color: `TH_PANEL_ACTIVE` (active) or `TH_PANEL_OUTLINE`
- Rounding: `btheme.tui.panel_roundness * U.widget_unit * 0.5 / aspect`
- Closed: all corners rounded (CNR_ALL)
- Open: only bottom corners rounded

### Collapse Animation
```
ANIMATION_TIME     = 0.30 seconds
ANIMATION_INTERVAL = 0.02 seconds (50 FPS refresh)
interpolation: fac = sqrt(fac), clamped [0.0, 1.0]
```

### Panel Constants
```
PNL_ICON         = UI_UNIT_X          // icon column width
UI_PANEL_MARGIN_X                     // horizontal margin
UI_PANEL_MARGIN_Y                     // vertical margin
sub_panel_pad    = U.widget_unit * 0.1 / aspect
drag_area_width  = PNL_ICON * 1.5
pin_area_width   = PNL_ICON
drag_widget_y    = ymin + (header_height - header_height*0.7) * 0.5
drag_widget_x    = xmax - scaled_unit * 1.15
```

## 7. 3D VIEWPORT DRAWING (view3d_draw.cc)

### Drawing Order (`view3d_main_region_draw`)
1. `view3d_draw_view()` - main scene via DRW draw manager
2. Free old subdivision caches
3. Disable depth testing: `GPU_depth_test(GPU_DEPTH_NONE)`

### Overlay Drawing Order (`view3d_draw_region_info`)
1. NDOF guide (if enabled)
2. Mini axis widget
3. Border/passepartout (camera view)
4. Text overlays (FPS, viewport name, selected objects info)
5. Performance statistics

### Axis Drawing (`draw_view_axis`)
- Position: `startx = rect.xmax - (k + UI_UNIT_X * 1.5)` where `k = U.rvisize * UI_SCALE_FAC`
- Line width: `2.0`
- Colors: `TH_AXIS_X` (red), `TH_AXIS_Y` (green), `TH_AXIS_Z` (blue)
- Alpha: `hypot(vec[0], vec[1])` (screen-space projected length)
- Brightness offset: `-20 * (10 - U.rvibright)`
- Rendered as `GPU_PRIM_LINES`, 6 vertices (3 axes, 2 verts each)

### Constants
```
M_GOLDEN_RATIO_CONJUGATE = 0.618033988749895
VIEW3D_OVERLAY_LINEHEIGHT = style.widget.points * UI_SCALE_FAC * 1.6
```

### Background & Grid
Background gradient and grid rendering delegated to DRW draw manager (not in this file).
Grid colors from theme: grid {84,84,84,128}, grid_major {84,84,84,255}.

## 9. OUTLINER DRAWING (outliner_draw.cc)

### Row Dimensions
- Height: `UI_UNIT_Y` per row
- Width per restrict column: `UI_UNIT_X`

### Indentation
- Text start: `te.xs + 1.8 * UI_UNIT_X`
- Child elements indented recursively via subtree traversal

### Visibility Culling
```
visible if: te.ys + 2*UI_UNIT_Y >= v2d.cur.ymin && te.ys <= v2d.cur.ymax
```

### Drawing Order
1. Background / selection highlight
2. Expand/collapse triangle
3. Type icon
4. Text name at `spx = te.xs + 1.8 * UI_UNIT_X`
5. Mode column (optional toggles)
6. Warning column (error indicators)
7. Restrict columns (right side)

### Restrict Columns (right to left)
Each `UI_UNIT_X` wide, offset from `v2d.cur.xmax`:
1. `SO_RESTRICT_INDIRECT_ONLY` (holdout)
2. `SO_RESTRICT_HOLDOUT`
3. `SO_RESTRICT_RENDER` (camera icon)
4. `SO_RESTRICT_VIEWPORT` (monitor icon)
5. `SO_RESTRICT_HIDE` (eye icon)
6. `SO_RESTRICT_SELECT` (cursor icon)
7. `SO_RESTRICT_ENABLE` (view layer only)

### Text Button Width
```
dx = v2d.cur.xmax - (spx + restrict_column_width + 0.2 * UI_UNIT_X)
```

## 10. TIMELINE / ACTION EDITOR (action_draw.cc)

### Channel Drawing (two passes)
**Pass 1 - Backdrops**: colored rectangles per channel row
```
immRectf(pos, v2d.cur.xmin, ymin, v2d.cur.xmax + EXTRA_SCROLL_PAD, ymax)
```

**Pass 2 - Widgets**: interactive elements via `ANIM_channel_draw_widgets()`

### Constants
```
EXTRA_SCROLL_PAD   = 100.0    // horizontal scroll padding
cache_draw_height  = 4.0 * UI_SCALE_FAC * pixelsize
```

### Current Frame Indicator
- Black vertical line at `saction->timeslide`
- From `v2d.cur.ymin - EXTRA_SCROLL_PAD` to `v2d.cur.ymax`
- Only drawn when `SACTION_MOVING` flag set

### Cache Bar Colors (hardcoded)

## 12. GPU SHADER PATTERNS (for Rust translation)

### Immediate Mode (simple geometry)
```
immBindBuiltinProgram(GPU_SHADER_3D_UNIFORM_COLOR)
immUniformColor4fv(color)
immBegin(GPU_PRIM_LINES, vertex_count)
  immVertex2f(pos, x, y)
immEnd()
immUnbindProgram()
```

### Widget Batch Mode
```
GPU_batch_program_set_builtin(batch, GPU_SHADER_2D_WIDGET_BASE)
GPU_batch_uniform_4fv_array(batch, "parameters", count, data)
GPU_batch_draw(batch)
```

### Blending Modes
- `GPU_BLEND_ALPHA` - standard transparency
- `GPU_BLEND_ADDITIVE` - light accumulation
- `GPU_BLEND_ALPHA_PREMULT` - premultiplied alpha

### Anti-Aliasing
```
GPU_line_smooth(true)  // edge AA
GPU_polygon_smooth(true)  // fill AA
line_width = max(min(pixelsize/5.0 * abs(half_width - 4.0), pixelsize), 0.5)
```

## 13. KEY UI_UNIT CONSTANTS

These are the base scaling units used throughout Blender's UI:
```
UI_UNIT_X = 20 * UI_SCALE_FAC    // base horizontal unit (~20px at 1x)
UI_UNIT_Y = 20 * UI_SCALE_FAC    // base vertical unit (~20px at 1x)
UI_SCALE_FAC = U.scale_factor     // user DPI scaling (1.0 default)
U.widget_unit = UI_UNIT_Y         // commonly referenced as widget_unit
U.pixelsize = 1.0                 // pixel scaling for retina
```

For your Rust egui port, `UI_UNIT_X`/`UI_UNIT_Y` correspond roughly to egui's spacing/interact sizes.
